# 📊 Job Market Analysis Using Web Scraping

## 📌 Project Overview

This project analyzes Data Analyst job-market information collected through Python-based web scraping.

The scraped job information was cleaned, transformed, and analyzed to identify patterns in job titles, companies, locations, experience requirements, salaries, industries, employment types, and technical skills.

The project demonstrates an end-to-end Data Analytics workflow, from web data collection to business insight generation.

---

## 🎯 Objectives

- Scrape Data Analyst job postings using Python
- Extract structured job-market information
- Clean and standardize raw scraped data
- Analyze hiring locations and companies
- Analyze experience requirements
- Explore advertised salary ranges
- Identify frequently requested technical skills
- Analyze skill combinations
- Create professional data visualizations
- Generate business insights from the collected data
